# LinkHelper

An ExileApi plugin for linking real players (party members) with skills
like Flame Link or Soul Link. It draws a circle under nearby players,
highlights whichever ones are missing your link, and can re-cast the link
for you automatically.

Based on the work of Relekto who created [LuminaryHelper](https://github.com/Relekto/LuminaryHelper), which did the same for
Minions (Spectres, Mercenaries, Animate Guardian) using Flame Link.

Built with AI assistance (Claude).
